# منصة التقارير المدرسية

النسخة التنفيذية المعتمدة لتصميم منصة التقارير المدرسية الخاصة بـ:
**الابتدائية الحادية عشر ومتوسطة حفصة بنت عمر برفحاء**

مديرة المدرسة: **منار بنت مفلح الشمري**  
صاحبة المبادرة والتصميم: **فاطمة الشمري**

## تشغيل النسخة مباشرة
افتحي `index.html`. إذا لم تضعي بيانات Supabase ستعمل المنصة في الوضع المحلي وتحفظ التقارير على نفس الجهاز.

## ربط Supabase
1. افتحي Supabase ثم SQL Editor.
2. شغّلي ملف `supabase-schema.sql` كاملًا مرة واحدة.
3. من Authentication > Providers فعّلي Anonymous Sign-ins.
4. افتحي `config.js`.
5. ضعي Project URL مكان `PUT_YOUR_SUPABASE_URL_HERE`.
6. ضعي Publishable / anon key مكان `PUT_YOUR_SUPABASE_PUBLISHABLE_KEY_HERE`.
7. ارفعي الملفات إلى الاستضافة.

## الملفات
- `index.html` واجهة المنصة.
- `styles.css` الهوية البصرية المعتمدة.
- `app.js` وظائف القوالب والحفظ والأرشيف والإحصائيات والطباعة.
- `templates.js` مكتبة القوالب الـ 36.
- `config.js` إعدادات المدرسة وSupabase.
- `supabase-schema.sql` الجداول والصلاحيات والترقيم التلقائي.

## ملاحظات
- لا يوجد تسجيل دخول ظاهر للمستخدم. عند ربط Supabase تستخدم المنصة تسجيلًا مجهولًا في الخلفية.
- رقم التقرير يتم إنشاؤه تلقائيًا في قاعدة البيانات بصيغة `SCH-YYYY-CODE-0001`.
- اسم صاحبة المبادرة لا يظهر داخل التقرير المطبوع.
- الطباعة من المتصفح تتيح الحفظ بصيغة PDF.
